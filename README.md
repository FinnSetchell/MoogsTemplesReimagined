### ABOUT

Moog's Temples Reimagined brings new life to Minecraft's classic temple structures with enhanced and reimagined versions. This mod features beautifully redesigned desert and jungle temples that offer improved loot, better exploration experiences, and more engaging encounters. Built using the MoogsStructureLib framework, these structures seamlessly integrate into your world while maintaining the authentic Minecraft feel.

### REQUIREMENTS

**MoogsStructureLib** - This mod requires [MoogsStructureLib](https://www.curseforge.com/minecraft/mc-mods/moogs-structure-lib) to function. Please ensure it is installed alongside this mod.
